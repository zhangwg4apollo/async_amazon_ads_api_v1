# Brand suitability inventory tier (Supply)

The Brand suitability inventory tier dimension contains 1 field, listed below:

## Brand suitability inventory tier (Primary Key)

- **Reporting Field ID**: `brandSuitabilityInventoryTier.value`
- **Data Type**: `STRING`
- **Description**: The inventory tier that groups ad-eligible inventory to help balance reach with brand suitability preferences.
- **Required fields**: N/A
- **Complementary fields**: N/A
- **Version 3 Reporting Name (DSP)**: `inventoryTier (dspBrandSuitability)`
- **Version 3 Reporting Name (Sponsored Ads)**: N/A
