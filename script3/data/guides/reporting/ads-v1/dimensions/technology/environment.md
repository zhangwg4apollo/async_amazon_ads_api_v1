# Environment (Technology)

The Environment dimension contains 1 field, listed below:

## Environment (Primary Key)

- **Reporting Field ID**: `environment.value`
- **Data Type**: `STRING`
- **Description**: The environment used by the customer to view the ad like web or app.
- **Required fields**: N/A
- **Complementary fields**: N/A
- **Version 3 Reporting Name (DSP)**: `Environment`
- **Version 3 Reporting Name (Sponsored Ads)**: N/A
